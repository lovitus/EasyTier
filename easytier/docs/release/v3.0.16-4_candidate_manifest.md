## Frozen implementation scope

- Register configured and RPC-added connectors with their existing persistent retry semantics.
- Register persisted-only bootstrap URLs as per-instance runtime helpers without modifying user
  configuration or the on-disk bootstrap format.
- Stop scheduling new helper reconnect tasks while the primary peer map contains any registered,
  non-closed connection; resume on the existing manager tick when that map becomes empty.
- Allow an already in-flight helper attempt to finish once rather than introducing cancellation or
  another lifecycle state machine.
- Linearize Add, Remove, Clear, reconnect claim and reconnect completion so an in-flight task cannot
  resurrect a removed connector or overwrite a newer source classification.
- Leave foreign-network peer maps, connector transports, authentication, routing, packet forwarding,
  P2P discovery, QUIC, KCP and FakeTCP unchanged.
- Add no timer, event subscriber, cooldown sequence, persistent health state, configuration field or
  public API.
