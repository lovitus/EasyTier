# v3.0.16-1 Candidate Manifest

Status: READY_FOR_FOCUSED_REVALIDATION

## Purpose

Remove the configured initial node as a permanent single point of failure after
an EasyTier network has successfully joined the mesh at least once. A normal
Stop or Exit records the currently live outbound peer URLs, and the next start
uses that auxiliary snapshot as additional runtime-only bootstrap input.

## Immutable scope

- Base implementation: `7d5a4a08105a4e1fe803d8bcdf2db92a30f18f42`.
- Version: `3.0.16-1` on every Cargo, Tauri, GUI and Android delivery path.
- Leaf SHA: `682d1dc43585a703c993e8875fe4e937b1038733`.
- HEV SHA: `97e74f1068bd924e740032382cdc94ca83741ae6`.
- Save only live outbound EasyTier connection URLs during normal Stop or Exit.
- Prefer the original remote URL, fall back to the resolved URL, and never
  persist process-local `ring://` endpoints.
- Keep one small text file per stable network identity under the existing
  platform-managed configuration directory.
- Append valid cached URLs in memory after configured initial peers with exact
  deduplication; never rewrite TOML, GUI state, imported files or serialized
  initial peers.
- Replace the cache only with a non-empty live snapshot. An empty snapshot does
  not erase the last useful auxiliary data.
- Share the manager implementation across Core, GUI/Tauri, Android JNI, FFI and
  OHOS entry paths. No packet-path, routing, transport or protocol behavior is
  changed.
- Make the UPnP integration-test event waiter tolerate broadcast `Lagged`
  notifications while still failing when the channel closes. This is test-only
  hardening and does not alter production UPnP or hole-punch behavior.
- Consolidate the repository workflow rules and make the release operator reject
  published versions, pause before formal dispatch without exact-artifact
  attestation, and avoid requiring future evidence inside an immutable candidate.
- Excluded: timers, peer scoring, TTL, database state, crash-time persistence,
  automatic configuration migration and packet hot-path work.
