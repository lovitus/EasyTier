# EasyTier v3.0.15-2

This prerelease fixes an Android connection regression present since v3.0.6.

## Android fix

- Restore the intended mobile-platform behavior when `bind_device = true`.
- Android does not perform native interface enumeration because the VPN host
  owns underlying-network selection and socket protection. The cached underlay
  snapshot integration incorrectly rejected every initial connector before
  reaching that platform bypass.
- Prevent the repeated `bind-device connector has no underlay interface
  snapshot` connection failure and retry loop.

## Compatibility

- Linux, Windows, BSD and ordinary macOS retain strict fail-closed snapshot
  validation.
- iOS, OHOS and macOS Network Extension retain the same platform-owned network
  boundary as Android.
- No configuration migration is required.
- VPN lifecycle, routing, DNS, transports, policy engines, Leaf, Mihomo and GOST
  behavior are otherwise unchanged.
