Status: RELEASED

## Immutable scope

- Base: post-release documentation commit `148edc2f77a8a4c3a07a855c3757e565637286dd`; runtime code is identical to the published `v3.0.13` tag before this batch.
- Restore descriptor validation before the legacy RPC compatibility return.
- Add an independent server dispatch-boundary descriptor check.
- Treat a closed RPC response receiver as a stale response and remove its inflight entry.
- Reject an empty Apple packet-info payload with `InvalidData` while preserving IPv4/IPv6 framing.
- Add focused unit coverage for valid/invalid legacy packets, live/closed response receivers, and empty/IPv4/IPv6 protocol inference.
- Update version and package metadata to `3.0.14` and add release notes.

- Upstream source inspected at `1e40350c896e2635fbb7cc2804819cd25001b028`.
