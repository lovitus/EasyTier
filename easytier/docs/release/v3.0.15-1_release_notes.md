# EasyTier v3.0.15-1

This release is only a release-process optimization trial. It is not recommended
as a routine upgrade for users already running a stable EasyTier release.

## Release process changes

- Validate the complete code batch on `.160` before any GitHub candidate build.
- Run Linux Profiling Beta as the mandatory optimized/debug artifact and automatic
  validation gate.
- Run Android Policy Candidate in parallel when Android validation is in scope.
- Start Core, GUI, Mobile, OHOS and Test together only after candidate validation.
- Reuse successful or active exact-SHA runs and cancel active peers on failure.
- Retry transient GitHub API failures without hiding persistent failures.
- Validate the cross-platform numeric prerelease version and required release
  documents before dispatch.

## Runtime compatibility

Runtime application functionality is unchanged from v3.0.14. Mesh, routing, RPC,
TUN, policy routing, Mihomo, Leaf, GOST, DNS, transports, GUI behavior and
configuration formats are unchanged.
