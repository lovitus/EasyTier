# v3.0.12 Candidate Manifest

## Scope

- Explicit Mihomo GeoX repair tool beside the stopped-network YAML Save action.
- Effective default and explicit `geox-url` resolution for inline `GEOSITE`,
  `GEOIP`, `SRC-GEOIP`, `IP-ASN`, and sub-rule usage.
- Operating-system proxy and explicit SOCKS5/SOCKS5H download modes.
- Transactional managed-home installation with native `mihomo -t` validation
  and rollback.
- Web, Tauri, and Core RPC exposure plus frontend and Rust regression tests.

## Explicit exclusions

- No automatic download during Save or startup.
- No YAML rewrite, provider-content interpretation, proxy/rule modification,
  controller hot update, routing, DNS, mesh, GOST, or Leaf behavior change.
