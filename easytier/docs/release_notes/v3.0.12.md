# EasyTier v3.0.12

EasyTier v3.0.12 adds an explicit repair tool for Mihomo GeoX resources on
networks where Mihomo's own direct downloader cannot reach the configured
resource URLs.

## Mihomo GeoX repair

- A wrench button beside Save in the stopped-network Mihomo YAML editor can
  prefetch the GeoX files required by inline `GEOSITE`, `GEOIP`, and `IP-ASN`
  rules.
- The tool resolves explicit `geox-url` values and the defaults of the bundled
  Mihomo release. `geodata-mode` selects `GeoIP.dat` or `geoip.metadb` exactly
  as Mihomo does.
- Downloads may use the operating system proxy or an explicitly entered
  `socks5://`/`socks5h://` endpoint. System mode uses Reqwest's native Windows,
  macOS, and environment proxy discovery.
- Downloads are size bounded and installed transactionally. Existing files are
  restored if the download or the authoritative native `mihomo -t` validation
  fails.

## Compatibility and boundaries

- Repair is explicit and never runs during Save or normal Mihomo startup.
- EasyTier does not modify the YAML and does not take ownership of Mihomo's
  provider, subscription, Dashboard, or normal resource-update lifecycle.
- The helper examines inline `rules` and `sub-rules`; it does not inspect the
  contents of remote rule providers.
- Leaf, mesh routing, TUN, GOST, DNS, and the Mihomo runtime supervisor are
  unchanged.
