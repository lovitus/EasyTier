# EasyTier v3.0.11

EasyTier v3.0.11 corrects the placement and completeness of the read-only
Mihomo runtime information introduced in v3.0.10.

## Runtime information

- An Info button immediately after Zashboard opens a compact runtime summary.
- The summary includes status, version, PID, restart count, active TUN, Mesh
  SOCKS entry, and enabled mixed/HTTP/SOCKS listeners.
- Listener endpoints include the exact active `bind-address` returned by the
  running Mihomo controller, including loopback, wildcard, IPv4, IPv6, and
  custom values.

## Compatibility

- This is a read-only presentation change. It does not hot-update Mihomo,
  rewrite YAML, add controller polling, or change network lifecycle behavior.
- A newer GUI connected to an older Core still displays available ports without
  claiming an unknown bind scope.
