# EasyTier v3.0.15-2

This prerelease fixes an Android connection regression present since v3.0.6.

## Fixed

- Android networks using the default `bind_device = true` setting no longer fail
  every initial-node connection because a native underlay interface snapshot is
  unavailable.
- The associated once-per-second failed connection retry loop is removed.

## Compatibility

- Native desktop and server platforms retain fail-closed interface snapshot
  validation.
- Mobile VPN hosts continue to own underlying-network selection and socket
  protection.
- No configuration migration is required.
