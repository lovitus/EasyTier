# EasyTier v3.0.16-1

This prerelease improves restart resilience after a network has joined the mesh
successfully at least once.

## Added

- Normal Stop and Exit now retain live outbound peer URLs as auxiliary
  bootstrap hints.
- Subsequent starts can reconnect through those cached peers when a configured
  initial node is unavailable.
- Multiple networks use independent snapshots derived from stable network
  identity.

## Safety and compatibility

- Cached peers are added only in memory; EasyTier never rewrites the user's
  configured initial nodes or imported configuration.
- Configured peers remain first, exact duplicates are removed, malformed lines
  are ignored and `ring://` endpoints are excluded.
- Empty shutdown snapshots do not erase the last useful cache.
- No configuration migration is required, and packet forwarding behavior is
  unchanged.
