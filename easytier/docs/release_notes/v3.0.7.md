# EasyTier v3.0.7 Release Notes

EasyTier 3.0.7 is a focused desktop GUI reliability update based on v3.0.6.

## Zashboard lifecycle

- Mihomo Zashboard now opens in a single EasyTier-managed webview window
  instead of the operating system's default browser.
- This avoids the Windows external-browser launch failure that could report a
  DLL initialization error followed by `os error 1223`.
- Repeated clicks reuse and focus the existing Zashboard window.
- Closing Zashboard destroys only that auxiliary window. Closing the main GUI
  continues to use EasyTier's existing background behavior.
- An unfocused Zashboard window closes after 15 minutes. The implementation is
  event-driven and does not add a polling loop.

## Security and compatibility

- The Zashboard webview is not included in the GUI's Tauri capability list and
  cannot invoke the main window's privileged plugin commands.
- Mihomo's controller remains bound to loopback. Existing controller URL and
  runtime secret handling are unchanged.
- Core networking, Mihomo configuration and process ownership, GOST, Leaf,
  Android, and OHOS behavior are unchanged from v3.0.6.

  避免 Windows 上的 DLL 初始化失败和 `os error 1223`。

- Zashboard 窗口不具备主 GUI 的 Tauri 插件权限；Mihomo controller 仍只监听
  loopback。
