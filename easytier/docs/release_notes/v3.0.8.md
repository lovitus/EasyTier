# EasyTier v3.0.8 Release Notes

EasyTier 3.0.8 reduces repeated failed automatic P2P connection attempts while
preserving the existing protocol-selection and hole-punch behavior.

## P2P connection-storm control

- A failed automatic P2P endpoint is identified by peer, protocol, IP, and port.
  Repeated complete failures cool down for 1, 2, 4, 8, then at most 10 minutes.
- Direct candidates, priority upgrade/fallback/probe, UDP hole punching, and
  TCP simultaneous-open use the same bounded failure table.
- A new peer, protocol, IP, or port is attempted immediately. Success clears
  the corresponding failure state.
- Direct and hole-punch internal retries, broadcasts, fanout, port guessing,
  and existing backoff rounds remain intact; one completed outer attempt is
  settled only once.
- The table is capped at 65,536 entries, sharded, and not accessed by established
  tunnel packet send/receive paths.

## Compatibility switch

Repeated-failure throttling is enabled by default. To restore the unrestricted
automatic P2P retry behavior from earlier releases, use one of:

```toml
[flags]
disable_p2p_storm_throttle = true
```

```text
--disable-p2p-storm-throttle
ET_DISABLE_P2P_STORM_THROTTLE=true
```

The same option is available in the GUI as **Disable P2P Storm Throttle**.
Enabling it clears existing cooldown state and bypasses the table at its shared
decision point. Turning it off again starts with an empty table.

Existing `lazy_p2p`, `need_p2p`, `disable_p2p`, transport priority,
upgrade/fallback/probe, relay, recovery, and hole-punch settings keep their
previous meaning. Manual connectors and established tunnel traffic are not
throttled.

## 中文摘要

- 自动 P2P 的完整失败现在按 peer、协议和目标 `IP:端口` 记录，重复失败依次冷却
  1、2、4、8、10 分钟，最高保持 10 分钟。
- Direct、协议升级/回退/探测、UDP 打洞和 TCP simultaneous-open 共用同一张有界表。
- 新 peer、新协议、新 IP 或新端口仍会立即尝试；成功会清除对应失败状态。
- 不减少一次 Direct 或打洞内部原有的重试、广播、fanout、端口猜测和 BackOff 阶段，
  一次完整外层事件只结算一次。
- 表最多保存 65,536 项，不进入已建立 tunnel 的收发包热路径。
- 如需恢复旧版本不受限制的自动 P2P 重试，可在配置、命令行、环境变量或 GUI 中开启
  `disable_p2p_storm_throttle`。该开关默认关闭。
