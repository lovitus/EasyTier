# EasyTier v3.0.10

EasyTier v3.0.10 is a focused desktop policy-runtime maintenance release based
on v3.0.9.

## Mihomo runtime controls

- The GUI can start, stop, or restart Mihomo for the current EasyTier process.
- These actions are runtime-only and never rewrite the selected backend or its
  YAML configuration.
- A manually stopped Mihomo starts normally again when the EasyTier network is
  started the next time.

## Runtime visibility

- The policy panel shows Mihomo's version, mixed/HTTP/SOCKS ports, and active
  TUN device when those values are already available in readiness state.
- Long configuration validation or first-time Geo resource downloads display
  `Policy Runtime Preparing` instead of appearing permanently stopped.
- The existing status polling path is reused; the GUI does not add a separate
  Mihomo controller polling loop.

## Reliability fixes

- A delayed stop task can no longer terminate a newer Mihomo process created by
  an automatic network restart or runtime restart.
- Saving a validated Mihomo configuration uses the normal network-controller
  path so restart and ownership behavior remain consistent.
- Leaf and Mihomo retain independent configuration and lifecycle state.

## Compatibility

- Mesh routing, GOST mesh entry, DNS behavior, proxy definitions, rules, and
  Mihomo YAML semantics are unchanged.
- The new controls are exposed only where the backend implements the runtime
  control API; web/mobile surfaces do not show non-functional controls.
