# EasyTier v3.0.15-1

This is a release-process and artifact-validation build. It is not recommended
as a routine upgrade for users already running a stable EasyTier release.

## Release engineering

- Correctly resolve versioned release branches from the latest `vX.Y.Z` tag.
- Refuse `.160` source synchronization while Rust or Node build processes are
  active.
- Preserve Cargo, Corepack, and Node dependency caches during source sync and
  delay stale-source deletion until the transfer succeeds.
- Install frontend dependencies incrementally from the frozen lockfile. The
  bounded dependency-reset path is explicit and restricted to known workspace
  directories.
- Provide one ordered remote preflight for Rust tests and frontend builds.
- Provide exact-SHA Core-first workflow dispatch, MIPS/MIPSel gating, duplicate
  dispatch prevention, formal workflow status, release audit, and Release launch.

## Runtime compatibility

- Runtime functionality is unchanged from v3.0.14.
- Mesh, routing, RPC, TUN, policy routing, Mihomo, Leaf, GOST, DNS, transports,
  GUI behavior, and configuration formats are unchanged.
