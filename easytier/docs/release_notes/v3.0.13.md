# EasyTier v3.0.13

EasyTier v3.0.13 extends the optional Mihomo initial-resource prefetch helper
to HTTP rule providers.

## Mihomo initial resource prefetch

- The stopped-network YAML editor wrench can prefetch both required GeoX data
  and every declared `type: http` rule provider through the system proxy or an
  explicitly selected SOCKS5/SOCKS5H endpoint.
- Explicit provider paths remain relative to Mihomo's instance-managed home.
  Providers without `path` use Mihomo's native `rules/<md5(url)>` cache name.
- Provider HTTP headers and positive `size-limit` values are honored.
- GeoX and rule-provider files are installed as one bounded transaction and
  committed only after native `mihomo -t` validation succeeds.

## Compatibility and boundaries

- This is an explicit initial-configuration helper. It never runs during
  ordinary Save, network start, or Mihomo's normal provider refresh cycle.
- User YAML, provider `proxy`, interval, ETag state, rules, proxies, and groups
  are not modified.
- `file` and `inline` rule providers are not downloaded.
- Targets outside the instance-managed directory, symlinked parent
  directories, and conflicting provider targets are rejected safely.
- Leaf, mesh, GOST, DNS, TUN, and the Mihomo supervisor are unchanged.
