# v3.0.16-2

## Changes

- Reduced the documented release path to four maintained operator commands.
- Starts the five formal workflows immediately after candidate success while exact-artifact and device validation run in parallel.
- Adds exact-SHA retry/resume handling for diagnosed infrastructure or flaky workflow failures.
- Removes unrelated historical recovery archives and parallel worktrees from routine release gating.

## Compatibility

- Runtime mesh, policy, GUI, mobile, and platform behavior is unchanged from v3.0.16-1.
- Existing low-level release commands remain available through `help-advanced` for recovery.
