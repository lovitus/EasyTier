# EasyTier v3.0.14

EasyTier v3.0.14 is a focused defensive-hardening release for peer RPC and
Apple TUN packet handling. It does not change routing, proxy, DNS, transport,
or configuration semantics.

## Reliability and input validation

- Legacy single-packet RPC requests must carry the same descriptor required by
  fragmented requests. Malformed peer input is rejected before dispatch.
- The RPC server retains a second descriptor check at its dispatch boundary so
  malformed input cannot become a process-wide panic in `panic=abort` builds.
- A response whose local receiver has already closed is treated as stale and
  removed instead of aborting the process.
- macOS and iOS packet-info conversion now rejects an empty IP payload with
  `InvalidData` instead of indexing past the buffer.

## Compatibility and boundaries

- Valid legacy and current RPC packet formats remain compatible.
- Normal RPC delivery, timeout handling, metrics, packet framing, and wire
  formats are unchanged.
- IPv4 and IPv6 packet-info generation retains the existing platform values.
- RPC timeout normalization and peer-ID collision recovery remain separate
  architectural hardening work and are intentionally not changed here.
