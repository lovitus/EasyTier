    generations so 32-bit MIPS retains the same `u64` generation semantics;
  - apply Clippy-equivalent test construction changes.

  - apply the Clippy-equivalent conditional form without changing invalidation
    events.
- `easytier/src/common/underlay_guard.rs`

  - replace one-element cloned slices with borrowed one-element slices in tests.
- `easytier-policy/src/windows.rs`
  - stop using public destinations such as `1.1.1.1` as route-readiness probes;
  - enumerate the local Windows route table and require the Leaf Wintun to own
    both IPv4 `/1` capture routes and, when enabled, both IPv6 `/1` routes;
  - permit legitimate more-specific DNS, proxy, mesh, and LAN bypass routes;
  - fail closed when a required route is missing or the same capture prefix is
    also owned by another interface;
  - add pure ownership tests for success, missing routes, competing routes, and
    more-specific bypass routes.
- `easytier/src/mihomo.rs`
  - canonicalize the Windows Mihomo managed home with `dunce` so `-d` receives
    a conventional drive/UNC path instead of a verbatim `\\?\` path;
  - preserve canonical symlink resolution and the existing managed-root
    containment check;
  - add a Windows regression test for the child-process path form.
- `easytier/Cargo.toml`, `Cargo.lock`
  - add the Windows-only `dunce` dependency; no non-Windows dependency edge is
    introduced.
