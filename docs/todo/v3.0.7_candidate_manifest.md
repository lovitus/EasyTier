## Code-review contracts

- Only the `main` window intercepts close requests and hides in the background.
- `mihomo-zashboard` and future auxiliary windows close normally.
- Focus restores cancel older idle-close generations.
- Only the current unfocused generation may close the dashboard.
- No polling loop is introduced.
- The dashboard label is absent from Tauri capability windows, so the remote
  dashboard cannot invoke main-window plugin permissions.
