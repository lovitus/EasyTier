# v3.0.7 Candidate Manifest

## Scope

Branch: `codex/v3.0.7-release`.

Base release: `v3.0.6`,
`a8a11c076c75a109c1fd882a32b206a60b0bf60f`.

The immutable candidate SHA and post-build run IDs will be recorded after the
candidate is committed. They are not part of this build snapshot.

Build-affecting changes:

- replace the GUI's system-browser Zashboard launch with one managed Tauri
  webview window;
- reuse and focus that window on repeated requests;
- preserve close-to-background behavior only for the main window;
- close an unfocused Zashboard window after a bounded 15-minute, event-driven
  timeout;
- align stale frontend tests with the already-released explicit backend and
  CodeMirror editor contracts without changing production behavior;
- update workspace, GUI, Web, Tauri, lockfile, and release metadata to 3.0.7.

Explicitly unchanged:

- Core packet, mesh, routing, DNS, policy, Mihomo, GOST, and Leaf semantics;
- Mihomo controller URL and runtime-secret generation;
- Android and OHOS behavior;
- dependency and sidecar pins.

## Code-review contracts

- Only the `main` window intercepts close requests and hides in the background.
- `mihomo-zashboard` and future auxiliary windows close normally.
- Focus restores cancel older idle-close generations.
- Only the current unfocused generation may close the dashboard.
- No polling loop is introduced.
- The dashboard label is absent from Tauri capability windows, so the remote
  dashboard cannot invoke main-window plugin permissions.
